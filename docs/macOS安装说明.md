# 班级智管-鸿升周老师 · macOS 版安装说明

> 适配 **macOS 27「Golden Gate」**：采用液态玻璃（Liquid Glass）专属界面 —— 贴边侧边栏、彩色导航图标、毛玻璃材质、统一圆角。
> 适用芯片：**Apple Silicon（M1 / M2 / M3 / M4 系列）**

---

## 一、安装步骤

1. 下载安装包：
   - `班级智管-鸿升周老师-1.2.0-macOS-arm64.dmg` —— 标准磁盘镜像，推荐
   - `班级智管-鸿升周老师-1.2.0-macOS-arm64.zip` —— 解压即用
2. 双击打开 `.dmg`，把 **班级智管-鸿升周老师** 拖入右侧 **Applications（应用程序）** 文件夹。
3. 从「启动台」或「应用程序」中点击图标运行。

---

## 二、首次打开被拦截？"已损坏，无法打开" / "无法验证开发者"解决方法

由于本软件暂未购买 Apple 开发者证书进行签名与公证（Notarization），通过 Edge/Safari/Chrome 等浏览器下载后，macOS 会给文件打上 `com.apple.quarantine`（隔离）标记；Gatekeeper 校验时发现"既没有签名、又带隔离标记"，就会**误报为「已损坏，无法打开」**——文件本身是完整的，按以下方法放行即可。任选其一：

### 方法 A：终端命令（针对"已损坏"弹窗最有效，推荐）

打开「终端」（应用程序 → 实用工具 → 终端），粘贴执行：

```bash
sudo xattr -rd com.apple.quarantine "/Applications/班级智管-鸿升周老师.app"
```

> 如果已经把 .app 解压到了「下载」或桌面等其他位置，把路径换成实际位置即可；
> 也可以先 `cd` 到 .app 所在文件夹，再执行：
> ```bash
> sudo xattr -rd com.apple.quarantine ./班级智管-鸿升周老师.app
> ```

输入开机密码后回车（密码不显示属正常），再双击图标即可正常打开。

### 方法 B：右键打开

1. 在「应用程序」文件夹中找到 **班级智管-鸿升周老师**。
2. **按住 Control 键点击**（或鼠标右键）图标 → 点击 **「打开」**。
3. 弹窗中再点 **「打开」** —— 之后就不会再拦截了。

> 若右键打开也提示"已损坏"，请使用方法 A 的命令清除隔离标记。

### 方法 C：系统设置放行

1. 打开 **系统设置 → 隐私与安全性**。
2. 向下滚动，找到关于本应用被阻止的提示 → 点 **「仍要打开」**。

> 出现过一次「已损坏」弹窗后，可先取消弹窗（不要移到废纸篓），执行方法 A 的命令后再打开。

## 三、通知授权（新消息提醒）

本版本已移除音视频（对讲 / 视频通话）功能，**不再需要麦克风、摄像头权限**。

当你在后台收到同事的新消息时，软件会弹出系统通知并把窗口置前。若首次未看到通知，请到
**系统设置 → 通知 → 班级智管-鸿升周老师**，确认「允许通知」已开启。

## 四、飞鸽传书（同网段即时通讯）端口提示

与 Windows 版一致，若无法发现对方或收发文件失败，请检查防火墙：

- **UDP 37123**（设备发现广播）
- **TCP 37124**（消息与文件传输）

系统弹窗询问是否允许传入连接时，点 **「允许」**；也可在
**系统设置 → 网络 → 防火墙** 中为本应用放行。两台设备需处于**同一网段**（同一 Wi-Fi / 路由器）。

> **v1.2.0 新增**：单文件传输上限提升至 **6GB**，并支持**整个文件夹发送**（递归传输、保留目录结构）；聊天记录**保存在本机、重启不丢失**，可在「飞鸽传书 → 聊天记录设置」中选择保留期（半年 / 一年 / 永久）。

## 六、常见问题

**Q：双击打开后闪退 / 图标点不动？**
A：先按「第二章」任一方法放行 Gatekeeper；若仍不行，到
**系统设置 → 隐私与安全性** 查看是否被记录为「已阻止」。

**Q：Intel 芯片的 Mac 能用吗？**
A：macOS 27 已不再支持 Intel 处理器。本包为 arm64（Apple Silicon）专用；老款 Intel Mac 请继续使用 macOS 14/15 并联系销售方获取旧版兼容包。

**Q：图标在 Dock 上显示不清晰？**
A：本版本已内置 1024px 液态玻璃图标，覆盖 16–1024 全尺寸；若 Dock 缓存异常，可注销重登或执行 `killall Dock`。

**Q：能否与 Windows 版互通局域网通信？**
A：可以。局域网通信基于 UDP/TCP 标准协议，macOS 版与 Windows 版在同一网段内可互相发现、互发文字与文件（含文件夹、大文件断点续传）。
